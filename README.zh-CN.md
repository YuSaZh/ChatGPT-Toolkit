# ChatGPT Toolkit 使用指南

版本 1.1.10（实验预览）。面向 ChatGPT 网页体验的独立中文 Tampermonkey 工具集；当前提供 Pro 本机计数、被动图片 / PoW 状态、可选账号分账及 WebDAV 同步。安装文件：`chatgpt-pro-counter.user.js`。

它统计安装后实际观察到的 Pro 请求，提供本周期已用、估算剩余、日志和手动校准。**Pro 次数不是 OpenAI 官方额度查询；默认上限 100 只是可修改的初始设置。图片行单独被动显示本页响应中的最近额度快照。**

**兼容性提示：悬停适配当前已知的输入框控件结构；ChatGPT 网页更新仍可能影响识别。合成测试不等于真实 Tampermonkey 注入与网页验收。**

## 安装与第一次设置

1. 安装或更新 [Tampermonkey](https://www.tampermonkey.net/)。WebDAV 同步要求 **5.5.1 或更新版**；低于此版本会拒绝联网同步，本机计数仍可使用。
2. 新用户点击 [安装 ChatGPT Toolkit](https://raw.githubusercontent.com/YuSaZh/ChatGPT-Toolkit/main/chatgpt-pro-counter.user.js)，在 Tampermonkey 中确认安装。**旧用户先导出备份，再从 Tampermonkey 的原脚本条目检查更新。** 1.1.9 会改变安装名；直接安装若出现新条目或副本，先保留旧条目，按下方“更名兼容”处理，不要删除旧记录。
3. 刷新 `https://chatgpt.com/`。正常启动后，右下角出现小巧的 `Pro 0/100 本机` 入口；有旧记录时显示原来的统计值。默认当前输入框选中 Pro 时，将鼠标停在原生 **Pro 或发送按钮** 上，会出现用量卡；可在设置中改为所有模型。原来的点击菜单和快捷键保留。如果连入口都没有，请检查 Tampermonkey 是否启用、该站点访问权限、浏览器的“允许用户脚本”权限。官方说明：[用户脚本权限](https://www.tampermonkey.net/faq.php#Q209)。
4. 点击右下角入口 →“设置”：填写你的实际上限、已确认的周期重置时间，以及安装前的“当前已用”。不知道初始用量时可暂留空，之后校准。
5. 正常使用 ChatGPT。安装前的历史不会补算；打开、刷新历史对话不会增加计数。

### 更名兼容

1.1.9 将安装列表中的 `@name` 从“ChatGPT Pro 本机计数器”改为 **ChatGPT Toolkit**，与项目和面板标题统一。`@namespace` 保留 `local.chatgpt.pro-counter`，`chatgpt-pro-counter.user.js` 文件名、`gpc.v1.` 存储键及 v1 备份 / WebDAV 计数文件格式均不变。主页、反馈及下载 / 更新地址指向 `YuSaZh/ChatGPT-Toolkit`。

[Tampermonkey 维护者说明](https://github.com/Tampermonkey/tampermonkey/discussions/1542)已有脚本通过 `@downloadURL` 更新可以随新源码更名，但保留 namespace **不等于**全新安装一定共享旧条目存储，实际结果仍需核对：

1. 先从旧脚本导出计数备份，记下需要核对的周期设置；不要删除旧条目。
2. 在 Tampermonkey 原条目中检查更新，核对来源并确认。由 ZIP / 粘贴安装或更新地址失效时，打开原条目的编辑器，用[新版完整源码](https://raw.githubusercontent.com/YuSaZh/ChatGPT-Toolkit/main/chatgpt-pro-counter.user.js)覆盖并保存。
3. 直接打开安装链接若创建了独立副本，停用多余副本，保留原条目并在其中更新；不要让两个副本同时记账。刷新后核对名称、历史、周期设置及同步配置。
4. 若选择改用独立的新安装，按需要导入备份并手动核对设置；WebDAV 凭据须在新安装中重新输入，导出文件不会带上凭据。确认历史无误前保留旧条目及备份。

本版未完成真实 Tampermonkey 的更名升级与存储保留验收，不能保证各种安装路径都自动复用原存储。新增的同页重复运行检查只是辅助保护，不能代替停用多余副本；尤其不能保证拦住在页面 body 出现前已启动的旧版。

### 1.1.10：输入与同步刷新修复

工具面板使用 Shadow DOM，网页全局事件处理可能把聚焦的工具输入框误认成普通页面区域。本版在脚本启动时为当前工具输入 / 选择控件隔离键盘、剪贴板、输入和组合输入事件，不取消普通编辑默认行为，不读取剪贴板、不模拟粘贴、不改变面板外输入事件。Esc / Alt+Shift+P 保留关闭功能；IME 组合期间不关闭。不能阻止更早已执行的页面监听；真实扩展、原生粘贴与输入法仍需实际环境验收。

异步同步进度、后台计数和错误提示只更新状态区域，不重建正在编辑的设置 / 同步表单。焦点、输入节点和草稿保留；较晚到达的保存结果不会覆盖继续编辑的内容。成功保存只清空仍与提交相同、且当前未聚焦的密码框。切换页签、账号模式和清除凭据仍按明确操作重置；旧设置表单的冲突校验不会被后台刷新解除。

### 1.1.9：精简提示与 WebDAV 基础目录

记录页只移除 PoW 解释段落，难度原值、是否要求和捕获时间仍保留；概览只移除页脚“只按实际请求模型/响应路由判断，订阅名称不会计数。”这一行，其他状态及账号共用周期说明保留。本文的 PoW / 计数安全边界仍适用。

新 WebDAV 配置默认填写基础目录，由脚本建立固定子目录并使用 `ChatGPT-Toolkit/data.json`。旧完整文件配置继续工作，切换位置必须显式选择；[配置与迁移步骤](#配置-webdav-跨设备同步)见下文。

### 1.1.8：PoW 与自动账号分账

“记录”页顶部显示最近被动捕获的 **PoW 难度十六进制原值**（保留前导零）、是否要求（仅接受真实布尔值）和捕获时间。没有捕获则显示“暂未捕获”。它只是本页最近响应快照，**不用于评价账号健康、模型能力或所谓“降智”**。不提取或保留挑战 seed、token、nonce，不求解、不调用 finalize；快照仅留在本标签页内存，账号 / 导航 / 生命周期边界清除。

在“设置 → 按当前账号自动切换账本”选择“实验自动识别”（**默认关闭，真实账号行为尚未验证**）：

- 只观察页面自己发出的同源 `GET /api/auth/session` 成功 JSON 响应，使用 `user.id`。不会主动查询账号、读取邮箱 / 姓名 / 令牌、解析 Cookie / JWT，也不从对话作者或菜单文案猜身份。
- 以登录用户生成固定 SHA-256 的 `a_…` 账本编号，同一用户在不同设备得到同一个编号；**同一用户的不同工作区共用账本**，本版不推断工作区身份。
- **只隔离记录；上限、统计方式和周期锚点仍是共用设置。** 不同账号的实际额度 / 周期可能不同，请切换后自行核对。不会自动获取官方 Pro 上限。
- 当前账号只存在本标签页内存，不会被另一标签页、导入或 WebDAV 的“当前账本”设置替换。每个发送请求在开始时锁定账本，迟到回包仍归原账本。
- 身份尚未知时显示“待识别”，新请求保存在本机的“未分配”账本；不计入默认或随后识别到的账号，也不上传 WebDAV。记录页可查看未分配记录；身份恢复后仍会提醒，并可导出核对或切回手动模式查看这些账本。不会自动搬移。
- **为避免跨账号误记，账号 / 会话请求、离开页面、失焦 / 隐藏、导航及输入区外的交互都会使识别失效。** 普通输入、悬停和工具面板内部操作不会清除。随后须等页面自然返回新的会话响应；没有响应就持续“待识别”，可刷新页面或使用手动模式。脚本不会为了恢复识别而额外联网。
- 原始用户 ID 不保存；生成的散列编号会随账号记录进入本地存储、导出和已启用的 WebDAV。**散列是可跨设备关联的假名标识，不是匿名化、加密或登录凭据。** 自动识别开关仅保存在本机，不随备份 / 同步；切换该模式会重建设置表单，请先处理未保存草稿。

升级不会迁移或改写默认账本旧历史。开启后从自然捕获到身份的新请求开始分账；如需补齐旧用量，请核对后手动校准。保留 `gpc.v1.` 键及 v1 数据格式，旧版本仍可读散列账本记录，但不具备自动识别能力。1.1.9 安装名更改的升级步骤见上文。

协议事实来源：[PoW 响应字段](https://github.com/zetaloop/chatgpt-checker-next/blob/0d7bf4a941ffa1dfa0c2bf7d3005a64be8a20825/chatgpt-checker-next.user.js#L4624-L4654)、[会话 user.id 的公开读取](https://github.com/jackwener/OpenCLI/blob/main/clis/chatgpt/auth.js) 和[已脱敏的实际响应结构报告](https://github.com/jackwener/OpenCLI/issues/2087)。只核对字段，自行实现观察器；未复制或执行参考项目代码。内部字段可能变化，真实账号行为仍待验收。

### 新版界面

1.1.7 将悬浮用量卡从 266 缩至 248 CSS 像素宽，内边距从 12×14 缩至 10×12 像素，主数字从 30 缩至 28 像素；图片剩余保持 11 像素灰字。长数字、读取时间和操作行可换行，窄窗口自动收缩。管理面板仍为 310 CSS 像素，显示模式及内容不变。

1.1.6 在“设置”顶部新增“悬浮卡显示”分段开关：

- **仅选择 Pro 时（默认）**：同一输入区可见的选择标签必须为 Pro；Thinking、Auto、其他模型或未知时不显示，切换离开 Pro 立即收起已有浮卡。`aria-hidden` 测量文字、订阅名称、历史消息、请求模型和默认模型均不能替代当前选择。
- **所有模型**：无论选中哪个模型，在已识别的原生发送 / 模型按钮上悬停或键盘聚焦均可显示。“一直显示”是指不受当前模型限制，不是常驻展开。

切换立即生效并单独保存，不提交或清空下面的周期 / 校准表单草稿。刷新后保留；本机界面偏好不进入导出、备份或 WebDAV。旧版导入和旧版设备同步不会覆盖偏好，也无需迁移原有 v1 账本。其他同浏览器标签页在获得焦点或下次本地刷新检查时跟随；其他设备独立选择。存储写入失败会显示提示，保持之前的选项；没有存储权限时仅在当前页临时生效。

概览面板宽度从 356 调整到 310 CSS 像素，窄窗口自动收缩；缩小内边距、数字与按钮，±1 校准同排，初始用量按钮更简洁，导入导出降为次级操作。通过实际 CSS 字号与布局压缩，不整体 transform 缩放；保留键盘焦点与完整文字标签。

- 默认只显示右下角小入口，不遮挡输入框；大面板按需展开。点击外部立即收起，入口仍在；面板内部和入口点击不会被误判为外部。关闭不抢走外部控件的焦点，也不拦截原生发送。
- 未保存的设置 / 同步字段仅保留在当前页面内存，重新点入口继续填写；关闭不会自动保存、测试或上传，刷新页面会丢弃草稿。密码草稿不写入存储、导出或同步。
- 满足所选显示模式时，鼠标悬停或键盘聚焦原生发送按钮，以大号数字显示剩余次数，同时显示紫色渐变进度条和 `已用 / 上限`。浮卡为原页面附加内容，优先放在按钮上方；空间不足时转到下方并留出原生提示空隙，不替换原控件或阻止其点击。
- 浮卡中的“管理用量”、右下角入口、Tampermonkey 菜单“显示 Pro 计数器”均可打开面板。快捷键 **Alt + Shift + P**；**Esc** 关闭面板。原生 **Ctrl + Shift + M** 不变。
- 本页新 Pro 请求首次被本机计入时，在输入框控件附近浮现约 1 秒的 `+1`。已计入消息的重试、重复响应、启动载入、导入、WebDAV 同步和手动校准不播放；未知模型、失败或取消未计入时不播放。后续流错误撤销计数时，也会撤销尚未显示或仍可见的提示。提示代表本机记账变化，HTTP 接收不等于官方扣额。
- 跟随网页深浅主题，并尊重减少动态效果设置。输入框被页面重新创建后自动重新识别；页面移除入口后自动恢复。
- 若识别不到新版原生控件，右下角入口仍可用。移动触屏没有鼠标悬停时，同样点击入口管理。
- `11/100` 只是用量示例，脚本不会硬写 11 次；已有使用量可在“设置 → 当前已用校准为”填写。

### 图片剩余行

Pro 剩余数字下方新增小号灰色“图片剩余”：被动观察本页原有 `POST /backend-api/conversation/init` 的成功 JSON 响应，从 `limits_progress` 中唯一的 `feature_name: image_gen` 项读取非负整数 `remaining`。0 会正常显示；缺失、重复、错误类型、负数和解析失败均显示“暂未获取”。不推算总上限、无限额度或重置时间，不把图片额度与 Pro 本机账本相加。

显示的是最近读取的快照，附读取时间，仅在当前页面内存中保留最多 60 秒。新初始化、发送等状态变更请求、账号 / 会话请求、导航、页面失焦 / 隐藏和输入区外的交互会清除旧值；普通输入、悬停和计数器内部操作保留快照。过期或清除后，等待页面自然产生新的有效响应，不额外发请求或轮询。

图片快照不写入 GM 存储、导出、备份或 WebDAV，不跨标签页共享。图片功能不提取登录令牌、Cookie 或账号身份；只克隆额度响应，读取最多 64 KiB、最多等待 1.5 秒，保留页面原 fetch 参数、Promise 和 Response。内部接口可能变化，当前没有真实账号额度验证。

协议字段核对来自 [ChatGPT Checker Next 固定版本的响应观察](https://github.com/zetaloop/chatgpt-checker-next/blob/0d7bf4a941ffa1dfa0c2bf7d3005a64be8a20825/chatgpt-checker-next.user.js#L4759-L4781)。该参考项目采用 AGPLv3；本仓库仅核对公开协议事实，新增解析、生命周期和界面为独立实现，未复制或执行参考源码。

### 启动兼容性说明

旧版有数条可用合成测试复现的空白界面路径：页面存在 `module.exports` 全局、页面强制 Trusted Types、存储 API 缺失或抛错、旧式主题监听接口，以及页面移除/替换挂载节点。1.1.0 已分别加入浏览器优先启动、纯 DOM 安全渲染、可见诊断、隔离主题异常、重新挂载。它们是已复现的代码路径，不能据此断言你的设备具体遇到了哪一种。

1.1.1 将“显示 Pro 计数器”和“诊断 Pro 计数器”菜单移到应用初始化之前。诊断显示启动阶段、页面检查、存储 / 菜单接口和 UI / 观察器状态；只包含固定阶段名与错误类型，不导出聊天、用量记录、凭据或完整异常消息。两项菜单都不可见时，请先核对版本、脚本启用状态与浏览器用户脚本执行权限。

1.1.1 也修复了合成测试中可复现的部分挂载失败恢复问题：一次性 Shadow DOM 创建失败不会再遗留不完整节点；首次渲染失败后重试会补齐悬停监听。**这些修复不能证明真实环境中不显示入口的问题已经解决。**

存储不可用时，入口显示“权限异常”，面板说明当前是否仅为临时计数；WebDAV 暂停。修复权限后刷新，临时记录不会自动当作旧存储数据导入。

## 被动只读边界

ChatGPT 部分只转发并观察网页本来发起的请求，不主动查询、重试、自动发送、切换模型或启用工具。保持原 fetch 参数、Promise / Response 和中断语义；只读取有上限的副本。Pro 计数为辨别模型和去重仍会读取已有请求的必要元数据，不保存聊天正文。

既有 WebDAV 是单独的主动同步功能，默认关闭；用户以前明确启用的配置升级后仍保留。要完全避免脚本主动联网，请保持关闭或清除已有配置。完整调用点、数据范围和验证限制见 [被动观察与网络审查](SECURITY.md)。

## 怎么计数

- 只观察当前页面发出的 `POST /backend-api/conversation` 和 `POST /backend-api/f/conversation`，不会主动查询隐藏 API、自动发消息或修改请求内容。
- 优先读取请求的 `model`。以独立 `pro` 标记判断 Pro；Thinking 不计入。请求模型未知时，只有响应中明确的实际路由字段才能补充判断。
- 订阅名称、`plan_type`、`default_model_slug`、历史 DOM 标签、回答语气或速度都不是计数依据。
- 请求收到 HTTP 2xx 后列为“已接收”，明确观察到失败、取消或应用错误则不计入。**接收不等于官方扣额成功，失败或取消也不证明平台未扣额。** 有差异时用 `+1 / −1` 或“当前已用校准为”修正。
- 已知 Pro 请求即使路由到其他模型，仍作为已接收的 Pro 请求记录。日志分别显示请求模型、实际路由和回答标签，不把它们混成一个字段。
- 同一用户消息的重试优先按稳定 ID 去重。编辑产生新消息 ID 时另计；重新生成优先用独立操作 ID。没有稳定 ID 时会明确提示“重试可能重复”，不会根据文本内容猜测。
- 页面离开、请求仍在等待、字段缺失等情况保留“待确认”或“模型未知”。未知模型不会自动算成 Pro。

### 周期与校准

- 固定七天：你指定锚点，每 **168 小时**一个周期。默认锚点是首次安装当天当地零点，必须按你的实际情况修改；夏令时变化不会把 168 小时变为自然周。
- 滚动七天：每条记录在经过 168 小时后退出当前窗口。
- “当前已用校准为”会新增差额记录，不会删除已有请求。固定周期到下一期自动不再纳入；滚动模式中这条校准记录会整体在七天后退出，无法还原安装前每次使用的真实时间。
- 多个账号可开启可选的自动识别，也可手动选择独立账本。自动模式只分隔记录，上限 / 周期设置仍共用；身份不明时记录留在未分配账本，账本选错需手动校正。

## 配置 WebDAV 跨设备同步

默认不联网同步，不需要把密码发给任何人。配置由你在自己的浏览器内完成；只使用你信任的私有 WebDAV 服务。

### 新配置：填写基础目录

1. 在自己的 WebDAV 服务上准备一个**已存在的私有基础目录**，例如 `https://你的服务器/dav/`。推荐单独创建应用密码，仅授权该目录。
2. 在浮窗“同步”页选择“基础目录”模式，填写这个 HTTPS 目录。末尾 `/` 可省略；基础目录路径不能含重复 `/`；安全的 Unicode 目录名可使用，并按 URL 规则编码，已有合法编码保持。不要在此模式填写 `data.json` 文件地址。
3. 脚本固定使用该目录下的 `ChatGPT-Toolkit/` 子目录及 `data.json` 文件，上例最终为 `https://你的服务器/dav/ChatGPT-Toolkit/data.json`。不会修改基础目录之外的路径，也不会递归创建缺失的祖先目录。
4. 填入用户名与密码，核对界面中的目标路径，勾选建目录、同步与本机保存凭据的授权说明，再点“测试并保存”。**此操作可能先用 `MKCOL` 创建子目录，然后用 `GET` 测试文件读取，并不只读。** `data.json` 可以尚不存在；读取测试不创建或覆盖计数文件，也不能证明条件写入可用。
5. 点击“立即同步”，才会合并本机与远端记录并条件写入 `data.json`。另一台设备选择相同模式、相同基础目录并填写该设备自己的凭据，即可同步。
6. 自动同步默认关闭。需要时选择每 5 / 15 / 30 / 60 分钟；**只有 ChatGPT 页面打开时运行**，浏览器休眠或关闭不会继续同步。同步失败时本机记录保留，网络恢复后可再同步；自动模式在下个间隔重试。

### 自动拉取与刷新时机

自动同步默认关闭。通过测试且明确授权后，选择 5 / 15 / 30 / 60 分钟，脚本在页面打开时每 15 秒检查是否到期；到期后即使本机没有新记录，也先 GET 云端记录、合并、条件 PUT，成功后更新本机记录及显示。同步页 / 设置页打开时入口数字和同步提示也会刷新，正在编辑的表单保留。

“测试并保存”可能 MKCOL 建目录，但只验证文件读取，不导入远端记录、不 PUT 计数文件。保存后等所选间隔才首次自动合并；要马上拉取请点“立即同步”。自动同步不是推送，关闭页面时不运行，休眠 / 后台节流可能延迟。GET 成功而 PUT 失败时，本轮远端数据尚不落入本机，不报告成功，到期后重新尝试；本机记录不会丢弃。

合并按记录 ID 和更新时间去重，计数仍只统计当前账本 / 周期的已接收 Pro 与手动校准；失败、待确认和其他模型记录虽可同步但不算已用。同步期间新到的本机记录和较新设置会保留，未进入这次上传的变更留待下一轮。

合并后超过 20,000 条可同步记录或 5 MiB 时停止写入，不创建本轮备份、不 PUT、不导入或自动删历史，避免生成下一台设备无法读取的远端文件。请先导出完整副本留存并人工整理；超过同一上限的导出文件也不能直接导入，脚本没有自动截断或分片功能。未分配账号记录本来不上传，因此不计入这一上载条数。

### 旧配置与明确切换

旧的无版本连接配置按**完整文件地址**解释，继续读写原 URL；即使文件没有扩展名，也不会被猜成基础目录。新连接配置使用 `version: 2` 与明确的 `mode`；基础目录模式是 `mode: 'base'`，其保存 URL 是规范化后的基础目录。连接配置版本不改变 v1 计数文件 / 备份格式。

同步页仍可明确选择“完整文件地址”模式，填写旧的最终 HTTPS 文件 URL，例如 `https://你的服务器/dav/pro-counter.json`。该模式不创建 `ChatGPT-Toolkit/`，父目录必须已存在；只对指定文件 GET / 条件 PUT，升级不会静默迁移远端文件。

从旧文件切到基础目录时：

1. 先保持旧配置，完成一次同步，确认旧远端历史已合并到本机，然后导出备份。若旧文件读不到，先解决该问题，避免遗漏只存在旧远端的记录。
2. 所有参与同步的设备都明确改为“基础目录”模式并填写同一个目录，测试并保存。
3. 在新位置首次同步，会合并**本机已有记录**与新位置的远端记录。脚本不会自动把旧远端历史复制过来，也不会在新旧两个地址之间桥接同步。
4. 核对各设备历史与设置后保留旧文件作为回退副本；脚本不会删除或移动它。仍用旧地址的设备不会收到新位置的更新。

### 同步安全与错误处理

- 只接受 HTTPS；拒绝 URL 内嵌用户名 / 密码、查询参数、片段、反斜杠、编码的斜杠 / 反斜杠、`.` / `..` 穿越段及有歧义的百分号路径。不会静默修正危险路径。基础目录拒绝重复 `/`，避免不同服务器把折叠后的路径视为其他位置；完整文件模式保留原路径中的重复 `/`。请使用服务提供的最终地址，不跟随 HTTP 重定向。
- 基础目录模式只向固定子目录发 `MKCOL`。201 表示新建；405 可能表示已存在，仍须继续 `GET data.json` 验证，不能仅凭 405 宣布可用。409 表示配置的基础目录缺失或路径冲突，请先在服务端建立正确目录或修正地址；脚本不会递归建目录。其他失败也停止后续操作。
- 使用无 Cookie 的 `anonymous` 请求。WebDAV Basic 认证凭据只发送给所配置服务器，不会发送 ChatGPT Cookie 或登录令牌；不会跟随重定向转交凭据。
- 安装声明中的 `@connect *` 用于自选 WebDAV 域名。未配置并授权时，不发送 WebDAV 请求。熟悉脚本的用户可将其改为自己的固定域名以缩小权限。
- 远端计数文件存在时必须有**强 ETag**，写入使用 `If-Match`；不存在时使用 `If-None-Match: *`。读失败、文件格式不对或缺少强 ETag 时停止，绝不盲目覆盖。读取测试成功或有 ETag 并不证明服务器正确执行条件写入，需使用确实支持该语义的服务。
- 并发冲突会重新读取、按事件 ID 合并，再条件写入，最多三轮；仍冲突则保留本机数据，稍后重试。单次 WebDAV 请求限时 20 秒，响应及合并文件上限 5 MiB。不会主动删除远端文件。
- 同步内容包括已分配账本的计数事件、模型标记和共用设置；未分配记录只留本机。共用设置包括上限、周期、锚点、手动选择的当前账本，按更新时间合并；当前标签页的自动账号身份不会被远端覆盖。请保持设备时钟准确，避免同时编辑设置。
- 地址和凭据只保存在本机 Tampermonkey 存储，**不进入脚本导出文件、远端计数文件或自动备份**。本机存储不是加密保险箱；不要共享浏览器配置文件，脚本管理器自己的完整设置备份也可能包含它们。
- “清除本机凭据”取消本页正在进行的同步并清除连接配置；取消或配置变化会阻止后续写入。本机计数和远端文件保留；已经发出的服务器请求可能已完成，取消不能撤销它。
- 此版本不提供端到端加密。服务端能看到同步的时间、模型标记、用量、设置及可跨设备关联的散列账本编号。不要使用公开共享文件地址。

本版尚未在真实 WebDAV 服务或真实 Tampermonkey 中验证建目录、权限、条件写入及升级流程；合成响应测试不能替代服务端验收。

## 导出、导入与备份

- “导出”保存 JSON；“导入合并”按记录 ID 去重合并，保留当前本机设置。不会因重复导入整份备份而重复计数。
- 导入前、修改设置前和同步前会保留本机快照。“最近备份”导出最近一次快照。自动快照最多使用 12 个轮换位置，同一分钟内会更新同一位置；重要历史请另外导出保存。
- 导入备份只合并，不会回滚/删除较新的记录，也不会自动恢复旧设置。需要回滚数字时，参考备份设置并手动校准。
- 单份导入/同步文件上限为 5 MiB，最多导入 20,000 条原始事件。本机日志浮窗显示最近 80 条，导出保留完整记录。本版本不自动清除历史。

## 隐私与观察范围

只持久保存随机事件 ID、去重 ID 的 SHA-256 摘要、时间、模型标记、状态、HTTP 状态码、手动校准量和设置。不保存提示词、回答正文、附件、Cookie、Authorization、原始请求/响应或 ChatGPT 登录信息。

为了提取必要元数据，脚本会在内存中短暂解析请求和响应的克隆副本，绝不会把它们整体保存或上传。请求体最多观察 1 MiB / 1.5 秒；响应最多观察 256 KiB / 30 秒，到达上限立即停止克隆分支观察，不中断页面自己的流。WebDAV 采用限时、限大小流读取。

## 已知限制与验证状态

- ChatGPT 的内部请求结构可能变化；XHR、WebSocket、跨页面恢复、移动 App 或脚本未运行时的使用不会自动补算。
- 部分回应转交 WebSocket。本版不监听 WebSocket；若已取得请求模型，仍可记录 HTTP 接收，实际路由可能显示未知。观察时间上限之后出现的错误也可能无法捕获，需要人工校准。
- 与其他包装 `fetch` 的扩展同时使用时可能冲突。脚本保留原 fetch 的调用参数、Promise、Response 和中断语义，仍无法保证所有第三方扩展组合兼容。若被覆盖，浮窗会提示刷新。
- 测试覆盖和运行结果见 [验证记录](docs/VALIDATION.md)。Node 和 Chromium 合成测试使用模拟的 DOM、请求与存储。
- **未连接真实 ChatGPT 账号或真实 WebDAV 服务；尚未完成真实 Tampermonkey 扩展注入验收。** 入口或菜单不显示的问题仍需在受影响环境确认，不能仅凭合成测试宣布解决。
