# 使用指南

[← 项目首页](../README.md) · [更新记录](../CHANGELOG.md) · [验证记录](VALIDATION.md)

适用于 **v1.1.24**。Pro 用量是本机估算，不是官方剩余额度。

## 安装与升级

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)，WebDAV 同步要求 5.5.1 或更新版本。
2. 打开 **[安装 / 更新链接](https://raw.githubusercontent.com/YuSaZh/ChatGPT-Toolkit/main/chatgpt-pro-counter.user.js)**，在篡改猴中确认。
3. 整页刷新 ChatGPT。右下角出现用量入口后，进入“设置”填写实际上限、周期锚点和初始已用量。

默认 `100` 只是可修改的初始上限。脚本不读取官方 Pro 上限，也不会补算安装前的历史。

### 更新脚本

更新前先导出 JSON 备份，再从篡改猴的**原脚本条目**检查更新。需要手动替换时，在原条目编辑器中用[完整源码](https://raw.githubusercontent.com/YuSaZh/ChatGPT-Toolkit/main/chatgpt-pro-counter.user.js)覆盖并保存。

如果出现重复副本，保留原条目和备份、停用多余副本，并核对记录与同步设置。不要让两个副本同时记账。

## 界面设置

| 入口 | 用途 |
| :--- | :--- |
| **概览** | 查看周期用量、剩余估算、待确认数，执行 ±1 或初始用量校准 |
| **记录** | 查看请求模型、实际路由与状态，进入“所有账本与备份” |
| **设置** | 配置上限、统计方式、周期锚点、账本与显示偏好 |
| **同步** | 配置 WebDAV，手动同步或设置自动间隔 |

面板最高 540px 且不超过视口高度的 68%；记录页顶部固定，仅列表滚动。点击外部、按 Esc 或 Alt+Shift+P 可关闭。设置和同步表单的草稿只暂存在本页，关闭不会保存，刷新会丢弃。

### 用量悬浮卡

悬停或键盘聚焦已识别的**发送 / 开始语音**按钮显示用量卡。模型选择入口不显示卡片，也不会自动开始语音。

- **仅选择 Pro 时**：默认选项，要求当前输入区明确选中 Pro。
- **所有模型**：其他模型或未知模型下也可通过发送 / 开始语音入口查看。

显示偏好立即生效，只保存在本机，不进入导出或同步文件。切换模型会收起旧卡片；原生按钮、菜单和发送操作保持原样。

### 消息模型与时间

在设置中选择“显示 / 隐藏”。助手操作按钮后内联显示实际响应模型、思考强度和时间；用户消息下显示时间。缺失元数据时不猜测。

| 消息日期 | 显示格式 |
| :--- | :--- |
| 今天 | 时:分 |
| 前七天 | 星期 + 时:分 |
| 更早 | 日期 + 时:分 |

当前实现只读取已提交的消息路径和已存快照，不包装原生组件、不调用应用 getter / subscribe / require。对话变化驱动更新，页面静止或标签隐藏时不反复扫描。没有可识别的消息锚点时省略标签。

### 图片与 PoW

图片剩余次数和 PoW 难度只取页面自然返回的数据，并标注最近捕获时间；没有新有效值时保留本页最近值。整页刷新或账号 / 会话边界后重新捕获。

这些快照仅留在本标签页内存，不写入账本、备份或 WebDAV。PoW 保留难度十六进制原值；是否要求可悬停难度查看。脚本不求解 PoW，也不据此判断账号健康或模型能力。

## 计数规则与账本

- 只记录脚本运行期间被动观察到的请求，不补算历史、App 或其他浏览器的使用。
- HTTP 已接收不等于官方已扣额；失败、取消、未知模型和观察中断需要结合实际情况核对。
- 模型按实际请求 / 响应字段识别，订阅名称或消息文案不能替代模型证据。
- 固定七天统计使用你设置的锚点；滚动统计按最近 168 小时计算。两者均是本机统计规则。
- 本页新 Pro 请求首次计入时的 `+1` 只表示本机记录变化，不代表官方扣额。

### 手动账本

默认手动选择账本。可以在设置中切换账本，分别记录不同账号的使用；上限、统计方式和周期锚点仍是共用设置，切换后请自行核对。

### 实验自动分账

默认关闭。开启后只观察页面自身的 `GET /api/auth/session` 成功响应，以 `user.id` 生成固定 SHA-256 账本编号；不主动请求身份，不读取邮箱、姓名或令牌。

同一用户在不同设备获得相同账本编号，同一用户的不同工作区共用账本。编号是可关联的假名标识，不是匿名化或加密。

身份未知时显示“待识别”，新请求写入本机“未分配”账本，不计入默认账号，也不上传 WebDAV。请求开始时锁定所属账本，迟到响应不会改记到随后切换的账号。

账号请求、导航、失焦 / 隐藏和输入区外的交互会使自动身份失效。须等页面自然返回新的会话响应才能恢复；持续待识别时可刷新页面或切回手动模式。旧默认账本和未分配记录不会自动迁移。

## 记录、导出与备份

| 内容 | 规则 |
| :--- | :--- |
| 本机记录 | 所有账本合计保留最新 **1000 条原始事件** |
| 记录列表 | 最多显示 1000 条，重试可能合并展示 |
| 自动备份 | **12 个轮换位置** |
| 导入 / 同步文件 | 最大 **5 MiB、20,000 条** |

修改设置、导入、同步及超限清理前会先保存本机快照。超出 1000 条时清理最旧记录；计数和导出基于保留记录，同周期超限可能减少计数。备份不计入这 1000 条，重要历史请另行导出。

“导入合并”按记录 ID 去重，保留当前设置，不会因重复导入整份备份重复计数。已按保留边界淘汰的旧记录不会重新导回；导入也不会回滚较新的记录或自动恢复旧设置。

从“所有账本与备份”可检查并单独导出有效备份。本机清理不会删除 WebDAV 远端历史。

## 配置 WebDAV 同步

WebDAV 默认关闭。需要篡改猴 5.5.1+，服务器须支持 **HTTPS、强 ETag 和条件 PUT**。请使用私有目录与最终地址，脚本不跟随重定向。

### 基础目录模式

1. 在服务器准备已存在的私有基础目录，例如 `https://你的服务器/dav/`。
2. 在“同步”中选择“基础目录”，填写上述目录地址及 WebDAV 凭据。
3. 核对目标，勾选同步与本机保存凭据的授权说明，再点“测试并保存”。
4. 点击“立即同步”，确认成功后，在另一台设备填写相同模式和地址。

脚本固定使用基础目录下的 `ChatGPT-Toolkit/data.json`。“测试并保存”可能通过 `MKCOL` 建立子目录，再用 `GET` 测试读取；不会 PUT 计数文件。首次文件可不存在，读取测试成功也不代表条件写入已经验证。“立即同步”才会合并记录并写回文件。

### 完整文件模式与自动同步

已有完整文件 URL 可继续使用；选择“完整文件地址”并填写原地址即可，该模式不建立子目录。升级不会搬移远端文件。更换地址前先同步旧文件并导出备份，再让各设备统一切换到新位置。

自动同步可选每 5 / 15 / 30 / 60 分钟，**只在 ChatGPT 页面打开时运行**。关闭、休眠或后台节流会停止或延迟执行。保存后等待所选间隔，或用“立即同步”马上合并。

同步先 GET、合并，再按服务器精确 ETag 条件 PUT；成功后才导入本轮远端记录。失败时保留本机记录。合并文件超出 5 MiB / 20,000 条会停止写入；本机导入后仍应用 1000 条保留规则。

WebDAV 凭据只保存在本机篡改猴中。同步文件没有聊天正文、Cookie、登录令牌或 WebDAV 密码，但包含用量元数据、设置和散列账本编号；当前版本不提供端到端加密。

## 常见问题

### 入口或标签不显示

先确认脚本已启用、运行于 `chatgpt.com`，并整页刷新。浏览器用户脚本权限说明见 [Tampermonkey FAQ](https://www.tampermonkey.net/faq.php#Q209)。

篡改猴菜单提供“显示 Pro 计数器”和“诊断 Pro 计数器”。没有元数据或无法识别页面结构时，标签会省略；诊断 ready 不代表所有消息数据已经读取成功。

### 计数变成零或提示待核对

保留原条目、备份和已知记录，先打开“本机数据检查”。它会列出所有账本、原始记录、有效备份及读取异常。显示用量受账本、周期和事件状态影响，0 不代表全部历史已消失。

读取失败时显示“待核对”，保留本页已知记录并暂停修改与同步。此时导出可能不完整，不要据此覆盖其他完整副本。

### WebDAV 报 HTTP 0、409 或 412

核对篡改猴版本、HTTPS 最终地址、目录、网络权限和服务端条件写入支持。HTTP 0 表示未取得有效响应，409 表示资源 / 目录冲突，412 表示条件写入未通过；它们不能单独证明其他设备正在写入。

当前版本已修复部分压缩 ETag 和空 204 响应造成的误报，并在 InfiniCLOUD 验证单设备同步。其他服务及双设备并发需要单独验收。

提供脚本版本、浏览器 / 篡改猴版本、复现步骤及脱敏诊断摘要。不要公开聊天内容、备份文件、WebDAV 凭据、Authorization 或完整网络日志。
