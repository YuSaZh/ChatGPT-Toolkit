# ChatGPT Toolkit

面向 ChatGPT 网页使用体验的非官方工具集。当前功能包括 Pro 本机计数、七天统计、手动校准、被动图片额度 / PoW 状态显示、可选账号分账、导入导出和可选 WebDAV 同步。

**1.1.12 实验预览：修复单条存储读取失败被误显示为归零的问题，新增所有本机账本 / 备份只读检查，阻止空文件上传并补充脱敏同步步骤诊断。** Pro 次数仍是本机估算；图片值只被动读取本页响应，不主动查询。与 OpenAI 无隶属或背书关系。

## 安装

1. 从 [Tampermonkey（篡改猴）官网](https://www.tampermonkey.net/) 安装适合浏览器的扩展。
2. **[点击安装 / 更新 ChatGPT Toolkit](https://raw.githubusercontent.com/YuSaZh/ChatGPT-Toolkit/main/chatgpt-pro-counter.user.js)**。
3. 在 Tampermonkey 安装页确认后刷新 ChatGPT。正常启动后右下角会出现计数入口；在“设置”中填写实际上限、周期锚点和已用量。默认 `100` 只是可修改的初始设置，不代表官方额度。

已有旧版本：**先导出备份，再从 Tampermonkey 中原来的“ChatGPT Pro 本机计数器”条目检查更新。** 直接打开安装链接若显示为新安装或出现副本，不要先删除旧条目；具体处理见下文。

## 图片额度与隐私

图片额度仅在当前页面内存保留最多 60 秒，不保存到脚本存储、导出、备份或 WebDAV，也不跨标签页共享。新初始化、发送、账号 / 会话请求、离开页面、导航或输入区外的交互会清除旧值；普通输入和悬停不会清除。脚本不额外请求接口，不提取登录令牌或 Cookie，也不在后台轮询。可选自动分账仅使用会话响应的用户 ID，见下文。

因此某些时候只会显示“暂未获取”，直到 ChatGPT 页面自然返回新的额度响应。该内部字段可能变化，本版未用真实账号验证返回行为。公开响应字段核对自 [ChatGPT Checker Next 的被动额度观察](https://github.com/zetaloop/chatgpt-checker-next/blob/0d7bf4a941ffa1dfa0c2bf7d3005a64be8a20825/chatgpt-checker-next.user.js#L4759-L4781)；只参考协议事实，未复制或运行该项目的 AGPL 代码。

## PoW 状态与自动账号账本

“记录”页顶部显示最近被动捕获的 **PoW 难度十六进制原值**（保留前导零）、是否要求（仅接受真实布尔值）和捕获时间。没有捕获则显示“暂未捕获”。它只是本页最近响应快照，**不用于评价账号健康、模型能力或所谓“降智”**。不提取或保留挑战 seed、token、nonce，不求解、不调用 finalize；快照仅留在本标签页内存，账号 / 导航 / 生命周期边界清除。

在“设置 → 按当前账号自动切换账本”选择“实验自动识别”（**默认关闭，真实账号行为尚未验证**）：

- 只观察页面自己发出的同源 `GET /api/auth/session` 成功 JSON 响应，使用 `user.id`。不会主动查询账号、读取邮箱 / 姓名 / 令牌、解析 Cookie / JWT，也不从对话作者或菜单文案猜身份。
- 以登录用户生成固定 SHA-256 的 `a_…` 账本编号，同一用户在不同设备得到同一个编号；**同一用户的不同工作区共用账本**，本版不推断工作区身份。
- **只隔离记录；上限、统计方式和周期锚点仍是共用设置。** 不同账号的实际额度 / 周期可能不同，请切换后自行核对。不会自动获取官方 Pro 上限。
- 当前账号只存在本标签页内存，不会被另一标签页、导入或 WebDAV 的“当前账本”设置替换。每个发送请求在开始时锁定账本，迟到回包仍归原账本。
- 身份尚未知时显示“待识别”，新请求保存在本机的“未分配”账本；不计入默认或随后识别到的账号，也不上传 WebDAV。记录页可查看未分配记录；身份恢复后仍会提醒，并可导出核对或切回手动模式查看这些账本。不会自动搬移。
- **为避免跨账号误记，账号 / 会话请求、离开页面、失焦 / 隐藏、导航及输入区外的交互都会使识别失效。** 普通输入、悬停和工具面板内部操作不会清除。随后须等页面自然返回新的会话响应；没有响应就持续“待识别”，可刷新页面或使用手动模式。脚本不会为了恢复识别而额外联网。
- 原始用户 ID 不保存；生成的散列编号会随账号记录进入本地存储、导出和已启用的 WebDAV。**散列是可跨设备关联的假名标识，不是匿名化、加密或登录凭据。** 自动识别开关仅保存在本机，不随备份 / 同步；切换该模式会重建设置表单，请先处理未保存草稿。

升级不会迁移或改写默认账本旧历史。开启后从自然捕获到身份的新请求开始分账；如需补齐旧用量，请核对后手动校准。保留 `gpc.v1.` 键及 v1 数据格式，旧版本仍可读散列账本记录，但不具备自动识别能力。1.1.9 安装名更改的升级步骤见上文。

协议事实来源：[PoW 响应字段](https://github.com/zetaloop/chatgpt-checker-next/blob/0d7bf4a941ffa1dfa0c2bf7d3005a64be8a20825/chatgpt-checker-next.user.js#L4624-L4654)、[会话 user.id 的公开读取](https://github.com/jackwener/OpenCLI/blob/main/clis/chatgpt/auth.js) 和[已脱敏的实际响应结构报告](https://github.com/jackwener/OpenCLI/issues/2087)。只核对字段，自行实现观察器；未复制或执行参考项目代码。内部字段可能变化，真实账号行为仍待验收。

## 被动只读边界

ChatGPT 部分只转发并观察网页本来发起的请求，不主动查询、重试、自动发送、切换模型或启用工具。保持原 fetch 参数、Promise / Response 和中断语义；只读取有上限的副本。Pro 计数为辨别模型和去重仍会读取已有请求的必要元数据，不保存聊天正文。

既有 WebDAV 是单独的主动同步功能，默认关闭；用户以前明确启用的配置升级后仍保留。要完全避免脚本主动联网，请保持关闭或清除已有配置。完整调用点、数据范围和验证限制见 [被动观察与网络审查](SECURITY.md)。

## WebDAV 基础目录与旧配置

新配置默认使用“基础目录”模式：填写已存在的 HTTPS WebDAV 目录，例如 `https://你的服务器/dav/`，脚本只在其下创建固定的 `ChatGPT-Toolkit/` 子目录，并读写 `https://你的服务器/dav/ChatGPT-Toolkit/data.json`。基础目录可有或没有末尾 `/`；基础目录路径若含重复 `/` 会拒绝并提示修正，不会静默折叠成另一个路径。不会递归创建你填写的父目录。勾选授权后，“测试并保存”可能发出 `MKCOL` 创建子目录，再 `GET` 检查计数文件；读取测试不证明条件写入可用，首次同步才会验证写入。

旧的无版本配置仍按**完整文件地址**使用，即使地址没有 `.json` 扩展名也不猜成目录；不会悄悄改到新位置。可在同步页明确选择保留完整文件模式或切换基础目录。切换前先用旧配置同步，让旧远端记录进入本机，再导出备份；随后所有设备选择相同基础目录，新位置首次同步会合并本机与新远端已有记录。旧远端文件保留，脚本不会自动复制、移动或删除它。

只接受 HTTPS，拒绝 URL 内嵌账号 / 密码、查询参数、片段、编码的斜杠 / 反斜杠、目录穿越与有歧义的百分号路径；可使用安全的 Unicode 目录名。不跟随重定向，不携带浏览器 Cookie。服务需支持强 ETag 和条件 PUT；`MKCOL` 返回 409 时，请先建立或修正所填基础目录。完整步骤、错误处理及安全限制见[中文使用指南](README.zh-CN.md#配置-webdav-跨设备同步)。

### WebDAV 显示 HTTP 0 时

1.1.11 修复了可由回调顺序触发的误报：流开始事件可能尚无 HTTP 状态，旧版却在流结束时沿用其状态 0，并忽略最终响应。新版同时等待有界流读取和最终响应，采用最终状态及 ETag；真正未收到 HTTP 响应时会提示检查扩展网络权限、连接或被拒绝的重定向，不再直接判断目录权限。此修复已通过模拟时序测试，尚未在受影响的真实 Tampermonkey / WebDAV 环境验证。

先从原脚本条目更新、刷新 ChatGPT 后再试。基础目录末尾 `/` 已由脚本补齐；不要仅为此改用别的域名。若此前建目录实际成功但显示失败，重试返回 405 后仍会继续读取验证。仍失败时，请提供提示和 Tampermonkey 版本，不要发送密码、Authorization 或完整网络日志。保持不跟随重定向与无 Cookie 请求。


## 计数归零或记录看不到时（1.1.12）

先保留当前脚本条目，不删除、不重装、不清理存储，也不要用新的校准覆盖印象中的旧用量。当前显示按账本、统计周期和事件状态过滤；显示 0 并不能证明原始记录已经消失。

从概览点“本机数据检查”，或 Tampermonkey 菜单点“检查本机计数数据”。检查只读当前安装条目的记录 / 设置 / 备份，显示：

- 原始记录键数、有效 / 异常记录数、读取失败数。
- 所有账本的记录数、去重数、周期内 / 周期外数量、Pro 和校准数量。只显示默认、账号、未分配、独立账本的临时编号，不显示账号散列、记录 ID 或自定义名称。
- 每份备份的日期和记录数；可单独导出有效备份。导出不会自动恢复、搬移或合并记录。备份文件含计数历史，不要公开分享；排障只需提供计数摘要。
- 本页最近 12 次 WebDAV 请求的 MKCOL / GET / PUT、耗时、HTTP 状态、流是否开始 / 结束、最终回调是否到达。日志只留在页面内存，刷新后清空；不会读取或记录地址、用户名、密码、Authorization 或响应正文。

某条记录或设置读取失败 / 格式异常时，不再把它静默丢弃后显示 0。界面显示“待核对”，保留本页已知记录并暂停数据修改与同步；此时导出只包含本页已知记录，可能不完整。备份槽不会被不完整读取覆盖，也不会用缺少历史 ID 的快照替换含那些历史的备份。若所有槽都含缺失历史，会停止本次修改，等待人工核对，不自动清理。

找到旧账本后，可在已有“设置 → 手动选择 → 账本”中核对并选择。自动账号识别不会把旧默认账本或未分配记录搬到新账号；未知账号继续明确显示“待识别”。本检查无法访问旧安装条目、其他浏览器 / 设备或远端文件，不能单凭当前条目为空判断所有副本已丢失。

同步仍先 GET 并合并；本机为空而远端有记录时可继续原有合并流程。但合并后没有可同步记录时，停止 PUT，不创建空计数文件，也不做只有设置的同步。PUT 409 表示资源冲突，412 表示条件写入未通过，均不能单独证明另一设备正在写。PUT 失败仍不导入本轮远端记录，不冒充成功。

存储写后读回仅检查脚本管理器当下返回的一致性，不等于验证磁盘落盘或浏览器重启后的保留。真实 Tampermonkey 持久化、实际 WebDAV 兼容性和用户记录恢复均需实际环境核对；本版不声称已经找回丢失数据。

## 自动拉取与计数刷新

- 自动同步默认关闭。已测试并授权后，可选 5 / 15 / 30 / 60 分钟；脚本在页面打开时每 15 秒检查是否到期。即使没有本机新记录，也会拉取云端、按记录 ID / 更新时间合并、条件写回；整轮成功后更新本机计数、周期设置、入口和同步状态。
- “测试并保存”可能创建同步目录，但仅测试文件读取，不导入云端记录或写计数文件。刚保存配置后，自动同步要等所选间隔；需要立刻合并时点“立即同步”。
- 这是双向合并，不是云端推送。页面关闭时不运行；休眠或后台节流可能延迟。GET 成功但 PUT 失败时不导入这轮云端记录、不显示同步成功；本机原记录保留，到期再试。
- 同步的是记录，显示计数仍按当前账本、周期、已接收 Pro 和手动校准计算；重试 / 重复记录不重复增加，失败或非 Pro 记录不算已用。账号上限 / 周期设置目前共用，仍需自行核对。
- 合并后超过 20,000 条可同步记录或 5 MiB 时，在本地备份、远端写入和本地合并前停止，不自动删除。请先导出完整副本留存并人工整理；超出同一导入上限的导出文件不能直接导回，脚本不会自动截断或拆分历史。

## 使用和限制

- 只记录安装后、脚本运行时观察到的请求，不会补算历史、跨浏览器或 App 的使用。
- HTTP 接收不等于官方扣额成功；模型未知、失败、取消等状态需结合实际情况手动校准。
- 默认不启用 WebDAV；只有自行配置并同意后，才向指定服务同步计数和周期设置。
- 不保存聊天正文、Cookie 或 ChatGPT 登录令牌。WebDAV 凭据保存在本机脚本管理器中，不包含在脚本导出或远端计数文件内。
- `@connect *` 用于支持自选 WebDAV 服务；不需要同步时可保持关闭。WebDAV 功能要求 Tampermonkey 5.5.1+，且服务端支持强 ETag 和条件写入。
