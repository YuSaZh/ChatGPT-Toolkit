ChatGPT Toolkit は **chatgpt.com** 向けの独立したユーザースクリプトです。Pro のローカル使用回数、メッセージのモデルと時刻、ページから受動的に取得した制限情報、任意の WebDAV 同期を提供します。

> **Pro の回数は、この端末での推定値であり、公式の残り回数ではありません。** OpenAI との提携関係や、同社による推奨はありません。

## 主な機能

| 機能 | 表示・管理できる内容 |
| :--- | :--- |
| **Pro 使用量** | 7 日間の集計、推定残り回数、未確定の状態、手動補正 |
| **メッセージ情報** | 実際の応答モデル、思考強度、ローカル時刻をメッセージの横に表示。取得できない値は推測しません |
| **使用量カード** | 送信 / 音声開始ボタンにカーソルを合わせて確認。Pro 選択時のみ、または全モデルで表示 |
| **画像・PoW** | ページ自身の応答から取得した画像生成の残り回数、PoW 難易度、取得時刻 |
| **帳簿・バックアップ** | 手動帳簿、実験的なアカウント自動識別、JSON 入出力、12 件の自動バックアップ |
| **WebDAV 同期** | 自分で設定したサーバーを使い、複数端末の記録と集計期間の設定をマージ |

コンパクトなパネルはライト / ダークテーマに対応しています。記録リストだけをスクロールでき、モデルと時刻はメッセージ内に配置されます。ページが静止している間、ラベルの再走査を繰り返しません。

## はじめに

1. [Tampermonkey](https://www.tampermonkey.net/) をインストールします。WebDAV には **5.5.1 以降**が必要です。
2. **[ChatGPT Toolkit をインストール](https://raw.githubusercontent.com/YuSaZh/ChatGPT-Toolkit/main/chatgpt-pro-counter.user.js)**し、確認後に ChatGPT を再読み込みします。
3. 右下の使用量表示を開き、設定で実際の上限、集計期間の基準日時、インストール前の使用量を入力します。

初期上限の `100` は変更可能な仮の値です。過去の使用量は遡って集計されず、会話を開いたり再読み込みしたりしても回数は増えません。

更新前にバックアップをエクスポートし、**既存の Tampermonkey エントリー**から更新してください。重複した場合は元のエントリーを残し、[更新手順（中文）](docs/guide.zh-CN.md#安装与升级)を確認してください。

## データと同期

- 全帳簿を合わせて、端末に**最新 1000 件**の記録を保持します。上限を超えると、バックアップ後に古い記録を削除します。自動バックアップは **12 枠**でローテーションします。
- 集計とエクスポートには保持中の記録を使います。同じ集計期間内に 1000 件を超えると、削除済みの記録は集計対象から外れます。
- **WebDAV は初期状態で無効**です。有効化後は設定したサーバーにだけ同期します。端末側の整理ではリモート履歴を削除しません。
- 会話本文、Cookie、ChatGPT のログイントークン、生の応答は保存しません。WebDAV の認証情報は端末のスクリプト管理機能にだけ保存し、エクスポートや同期ファイルには含めません。
- 画像・PoW は現在のページで最後に取得した有効な値です。ページ全体の再読み込みやアカウント境界の後は、ページから自然に返る新しい情報を待ちます。残り回数を能動的に問い合わせません。

設定やデータの扱いは、[使い方（中文）](docs/guide.zh-CN.md)と[プライバシー・安全性（中文）](SECURITY.md)を参照してください。

## 互換性

Vivaldi / Tampermonkey で、メッセージラベル、元のスクリプトエントリーの更新、InfiniCLOUD との単一端末での同期を確認しています。アカウント自動識別、新規メッセージのストリーミング、2 台の端末による同時同期は追加検証が必要です。詳しくは[検証記録（中文）](docs/VALIDATION.md)をご覧ください。

ChatGPT のページ構造や内部フィールドは変更されることがあります。観測できなかったリクエスト、アプリや別ブラウザーでの使用量は自動集計されません。問題があれば、Tampermonkey の「诊断 Pro 计数器」または「检查本机计数数据」を実行し、機密情報を含まない要約だけを共有してください。
